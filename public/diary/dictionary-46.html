A

await

/əˈweɪt/
動詞
1人・出来事・結果などが現れるまで待つ。返事が来るのを待ったが、ついに届かなかった。
2〈出来事などが〉将来に待ち受ける。彼らには別の未来が待っていた。
B

break

/breɪk/
動詞・名詞
1力・圧力・負荷などによって、ものを割る、壊す。枝は自重で折れた。
2続いているものの流れや連続性を中断する。突然の質問が沈黙を破った。
3活動の途中に入る休止、中断。彼らは続ける前に短い休憩を取った。
参照 continue
C

case

/keɪs/
名詞
1ある状況の個別の例。この場合、返答は必要なかった。
2検討や判断を要する一連の事情。事実関係は難しい問題を形づくっていた。
3ものを収め、保護する容器。器具はケースに入れられたままだった。

catch

/kætʃ/
動詞・名詞
1動いているものを受け止め、つかむ。彼女は落ちてきたグラスを受け止めた。
2短く、聞き逃しやすいものに気づく、聞き取る。最後の言葉を聞き取れなかった。
3予想外の条件や難点。ただし、一つだけ問題があった。
参照 throw

class

/klɑːs/
名詞
1共通する性質を持つものとして扱われる人や物の集まり。その標本はよく知られた分類に属する。
2大きな体系の中の等級、区分、類。切符は等級ごとに分けられていた。
3一緒に授業を受ける集団。そのクラスは週に二度集まった。

const

/kɒnst/
名詞・略語
1constant の略。変化しないもの、固定されたもの。議論を通じて、一つの値は const として扱われた。

continue

/kənˈtɪnjuː/
動詞
1止まらずに存在、作動、進行し続ける。雨は夜通し降り続いた。
2中断の後で再び始める。少し間を置いて、彼女は話を続けた。
3同じ方向や過程をさらに進む。道が細くなるところまで進み続けなさい。
参照 break
D

debugger

/ˌdiːˈbʌɡə/
名詞
1不具合、誤り、故障の原因を探し出し、取り除こうとする人またはもの。デバッガーは一度に一つの不具合を切り分けていった。

default

/dɪˈfɔːlt/
名詞・動詞
1別の指定がないときに適用される状態、選択、動作。沈黙が既定の状態になった。
2契約上の義務などを果たさないこと。その融資は債務不履行となった。
3求められた行為、出席、履行をしない。その選手は決勝前に棄権した。

delete

/dɪˈliːt/
動詞
1書かれたもの、記録されたもの、保存されたものを取り除く。彼女は最後の一文を削除した。
2不要になったものを消す、抹消する。いくつかの名前が一覧から削除された。

do

/duː/
動詞
1行為を行う、実行する。必要なことをしなさい。
2仕事や課題を完了する、処理する。仕事は正午までに終わった。
3ある仕方で行動する、ふるまう。あなたはよくやった。
E

else

/els/
副詞・形容詞
1すでに述べたもの以外に、またはその代わりに。ほかに何が言えただろう。
2別の、ほかの。別の誰かがすでに到着していた。

enum

/ˈiːnʌm/
名詞・略語
1enumeration の略。区別された複数の可能性を順に挙げること、またはその列挙。その目録は失われた形の enum のように読めた。

export

verb /ɪkˈspɔːt/ · noun /ˈekspɔːt/
動詞・名詞
1品物、資料、考え、データなどを外部へ送り出す。その地域は輸入よりも多くを輸出している。
2外へ送り出されるもの。茶は重要な輸出品になった。
比較 import

extends

/ɪkˈstendz/
動詞
1extend の三人称単数現在形。既存の限界を越えて伸びる、続く。道は木々の向こうまで伸びている。
2招待、好意などを差し出す。その招待はすべての会員に及んでいる。
F

false

/fɔːls/
形容詞
1事実や現実に合っていない。その報告は誤りだと判明した。
2本物に見せかけた、偽の。彼は偽名で旅をした。
3誤った信念や印象に基づく。彼らは誤った前提で行動した。
反対語 true

finally

/ˈfaɪnəli/
副詞
1一連の出来事や待機の末に、ついに。ついに扉が開いた。
2最後の点として、最後に。最後に、一つだけ問いが残った。

for

/fɔː; fə/
前置詞・接続詞
1誰か・何かに属する、利益を与える、届くことを意図して。この手紙はあなた宛てです。
2一定の時間、期間にわたって。彼らは三時間待った。
3〜のために、〜を理由として。その町は庭園で知られていた。

function

/ˈfʌŋkʃən/
名詞・動詞
1人や物が果たす目的、役割、働き。その鍵の機能は錠を開けることだ。
2より大きな全体の働きの一部としての活動。記憶はその体系の一つの機能である。
3正常または意図された通りに作動する。その装置は動作し続けた。
I

if

/ɪf/
接続詞・名詞
1ある条件が成り立つことを前提として。雨なら、私たちは中にいる。
2真偽の定かでない可能性を導く。誰かがそれを見たかどうか尋ねた。
3条件や但し書き。条件が多すぎた。
参照 else

implements

/ˈɪmplɪments/
動詞
1implement の三人称単数現在形。決定、計画、制度などを実行に移す。その政策は以前の合意を実施する。

import

verb /ɪmˈpɔːt/ · noun /ˈɪmpɔːt/
動詞・名詞
1品物、資料、考え、データなどを外部から取り入れる。その国は燃料の大半を輸入している。
2外部から取り入れられたもの。その果物は季節限定の輸入品だ。
3意味、重要性、重大さ。彼らは後になって、その決定の重大さを理解した。

in

/ɪn/
前置詞・副詞
1何かの内部、範囲、状態、期間のうちに。部屋の中に明かりがついていた。
2内部へ。中へどうぞ。
3参加している、含まれている。あなたも参加する？

instanceof

/ˈɪnstəns əv/
複合名詞
1instance of。ある広い種類に属するものとして見なされる、個別の例や出来事。その出来事は、より一般的な型の instanceof として扱われた。

interface

/ˈɪntəfeɪs/
名詞・動詞
1異なる二つのものが接し、相互に影響する境界。海岸線は陸と海の interface をなす。
2二つの主体、体系、領域がやり取りするための接点や手段。言語が両者の interface になった。
3そのような境界で相互作用する。二つの集団が直接 interface することはほとんどない。
L

let

/let/
動詞・名詞
1何かが起こることを許す。その件はそのままにしておきなさい。
2人や物が動く、行動することを可能にする。彼女は鳥を放した。
3ラケット競技などで、やり直しとなる中断。そのサーブは let と判定された。
N

new

/njuː/
形容詞・副詞
1以前は存在しなかった、新しく作られた、発見された、始まった。彼らは新しい道を開いた。
2その人にとって未経験、なじみがない。その町は彼女には初めてだった。
3新たに、改めて。彼らは新たに始めた。

null

/nʌl/
形容詞・名詞・動詞
1法的な効力や拘束力がない。その合意は無効とされた。
2何もない、効果がない、空である。実験は無結果に終わった。
3ゼロまたは空の値。その欄は null のままにされた。
参照 void
P

package

/ˈpækɪdʒ/
名詞・動詞
1包まれたり箱に入れられたりして、一つにまとめられたもの。小さな荷物が郵便で届いた。
2関連する複数のものを一つとしてまとめたもの。その施策は一つの package を形成していた。
3配布や提示のために包む、まとめる。商品は丁寧に包装された。

private

/ˈpraɪvət/
形容詞・名詞
1一人または限られた集団に属する、向けられた。彼らは私室で会った。
2公に知られたりアクセスされたりしない。その書簡は非公開のままだった。
3いくつかの軍隊で最下級の兵士。彼は一兵卒として勤務した。
比較 public

protected

/prəˈtektɪd/
形容詞
1害、損傷、干渉、望まない変更から守られている。その建物は法律で保護されている。
2特定の人、集団、目的のために確保されている。海岸の一部は保護区域である。

public

/ˈpʌblɪk/
形容詞・名詞
1限られた集団ではなく、人々一般に開かれた、関係する。その資料庫は一般に公開されている。
2他者が見聞きできる状態にする、公にする。その声明は公表された。
3人々を集合的に指す語。一般の人々も参加を招かれた。
比較 private
R

return

/rɪˈtɜːn/
動詞・名詞
1以前の場所、人、状態、活動へ戻る。彼女は暗くなる前に戻った。
2何かを返す、戻す。本を返してください。
3戻ること、帰還。彼の帰還で空気が変わった。
S

static

/ˈstætɪk/
形容詞・名詞
1同じ場所や状態にとどまり、動かない、変化しない。画像は静止したままだった。
2運動ではなく平衡状態の力に関する。計算では静的荷重を仮定した。
3無線や電気信号に入るパチパチ、サーという雑音。スピーカーからは雑音しか聞こえなかった。

super

/ˈsuːpə/
形容詞・副詞・接頭辞
1すばらしい、並外れている。とても楽しい夜だった。
2語の前について、通常を超える、上位の、大きなことを表す。その接頭辞は超人的な規模を示しうる。

switch

/swɪtʃ/
動詞・名詞
1一つのもの、位置、進路、状態から別のものへ切り替える。彼らは席を入れ替えた。
2接続を入切したり回路を切り替えたりする装置。彼は照明のスイッチに手を伸ばした。
3急な、あるいは意図的な変更。口調の切り替わりは即座だった。
T

this

/ðɪs/
限定詞・代名詞・副詞
1現在そこにある、近くにある、示されている、話題になっている人や物を指す。私が言っていたのはこれです。
2現在の時、状況、経験を指す。こんなことになるとは思わなかった。
3示された程度まで。これほど難しいとは思わなかった。

throw

/θrəʊ/
動詞・名詞
1腕や手の動きで物を空中へ放る。彼は石を水へ投げた。
2人や物を突然ある状態に陥らせる。その知らせは彼らを混乱に陥れた。
3投げる行為。それは長い投球だった。
参照 catch

true

/truː/
形容詞・副詞
1事実や現実に合っている。その話は本当だ。
2正確な、適切な位置や状態にある。その車輪はもはや正しく回っていなかった。
3誠実な、忠実な、一貫した。彼女は自分の言葉に忠実だった。
反対語 false

try

/traɪ/
動詞・名詞
1何かをしようと試みる。もう一度やってみなさい。
2品質、適性、効果などを確かめるために試す。彼女はその鍵を錠に試した。
3試み。次の試みではうまくいくかもしれない。

typeof

/ˈtaɪp əv/
複合名詞
1type of。物が属するとされる種類、型、分類。その対象はあらゆる typeof 分類に抵抗した。
V

var

/vɑː/
名詞・略語
1variable の略。異なる値や形を取りうる量、要素、条件。時間だけが制御されていない var として残った。

void

/vɔɪd/
名詞・形容詞・動詞
1本来何かがあり得る場所に生じた空所、空白、不在。音は虚空へ消えていった。
2何も含まない、ある性質や効果を欠く。その部屋には温かさが欠けていた。
3無効にする、効力を失わせる。その誤りは契約を無効にする可能性がある。
W

while

/waɪl/
接続詞・名詞・動詞
1別のことが起きている間に。私が探す間、ここで待っていて。
2〜ではあるが。その計画は難しかったが、可能だった。
3しばらくの時間。少しの間いてください。

with

/wɪð; wɪθ/
前置詞
1〜と一緒に、〜を伴って。彼女は友人と来た。
2〜を使って、持って、含んで。鉛筆で書きなさい。
3〜との関係で、〜に賛成して、〜に対して。私はあなたに同意する。
Y

yield

/jiːld/
動詞・名詞
1結果として生み出す、もたらす。その畑は毎夏穀物を産する。
2圧力、力、議論、要求などに屈する、譲る。その材料は変形し始めた。
3所有、支配、優先権などを譲り渡す。彼らはその場所を譲ることを拒んだ。
4産出量、収益量。収穫量は予想より少なかった。
