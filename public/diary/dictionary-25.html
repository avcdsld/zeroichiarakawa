編集方針

B

break

/breɪk/
動詞・名詞
1力、圧力、負荷などで割る、壊す。枝は自重で折れた。
2流れや連続性を中断する。質問が沈黙を破った。
3活動の途中に入る休止、中断。彼らは短い休憩を取った。
参照 continue
C

case

/keɪs/
名詞
1ある状況の個別の例。この場合、返答は必要なかった。
2検討や判断を要する一連の事情。事実関係は難しい問題を形づくっていた。
3ものを収め、保護する容器。器具はケースに入れられたままだった。

chan

/tʃæn/
名詞・略語
1channel の略。何かが移動したり伝えられたりする媒体、経路、通路。知らせは非公開の chan を通って届いた。

const

/kɒnst/
名詞・略語
1constant の略。変化しないもの、固定されたもの。計算を通じて一つの値は const のままだった。

continue

/kənˈtɪnjuː/
動詞
1止まらずに存在、進行し続ける。雨は夜通し降り続いた。
2中断の後で再び始める。少し間を置いて、彼女は話を続けた。
3同じ方向や過程をさらに進む。道が細くなるところまで進みなさい。
参照 break
D

default

/dɪˈfɔːlt/
名詞・動詞
1別の指定がないときに適用される状態、選択、動作。沈黙が既定の状態になった。
2契約上の義務などを果たさないこと。その融資は債務不履行となった。
3求められた行為、出席、履行をしない。その選手は決勝前に棄権した。
参照 switch

defer

/dɪˈfɜː/
動詞
1行為、判断、出来事を後の時点まで延期する。彼らは判断を朝まで延期した。
2他者の判断や意向を尊重して従う。彼女の経験に判断を委ねる。
E

else

/els/
副詞・形容詞
1すでに述べたもの以外に、またはその代わりに。ほかに何が言えただろう。
2別の、ほかの。別の誰かがすでに到着していた。
参照 if
F

fallthrough

/ˈfɔːlθruː/
名詞・形容詞
1本来区切られるはずの境界や段階で止まらず、その先へ進むこと。その隙間によって意図しない fallthrough が生じた。
2途中で停止せず、後に続くものへそのまま進む。その手順には fallthrough の経路があった。

for

/fɔː; fə/
前置詞・接続詞
1誰か・何かに属する、利益を与える、届くことを意図して。この手紙はあなた宛てです。
2一定の期間にわたって。彼らは三時間待った。
3〜のために、〜を理由として。その町は庭園で知られていた。

func

/fʌŋk/
名詞・略語
1function の略。人や物が果たす目的、役割、働き。その func は単純だが不可欠だった。
G

go

/ɡəʊ/
動詞・名詞
1ある場所から別の場所へ移動する、行く。彼らは暗くなる前に帰った。
2ある仕方で進行、継続、展開する。仕事は順調に進んだ。
3試み、順番、行動する機会。次はあなたの番です。

goto

/ˈɡəʊtuː/
形容詞・名詞
1頼りにされ、いつも優先して選ばれる人、物、方法。これは彼女の定番の参考資料になった。
2頼りになる定番の選択肢。それがチームの goto だった。
I

if

/ɪf/
接続詞・名詞
1ある条件が成り立つことを前提として。雨なら、私たちは中にいる。
2真偽の定かでない可能性を導く。誰かがそれを見たかどうか尋ねた。
3条件や但し書き。条件が多すぎた。
参照 else

import

verb /ɪmˈpɔːt/ · noun /ˈɪmpɔːt/
動詞・名詞
1品物、資料、考え、データなどを外部から取り入れる。その国は燃料の大半を輸入している。
2外部から取り入れられたもの。その果物は季節限定の輸入品だ。
3意味、重要性、重大さ。彼らはその決定の重大さを理解した。
参照 package

interface

/ˈɪntəfeɪs/
名詞・動詞
1異なる二つのものが接し、相互に影響する境界。海岸線は陸と海の interface をなす。
2二つの主体、体系、領域がやり取りするための接点や手段。言語が両者の interface になった。
3そのような境界で相互作用する。二つの集団が直接 interface することはほとんどない。
M

map

/mæp/
名詞・動詞
1場所や地形の相対的位置を示す表現、地図。彼らは机の上に地図を広げた。
2関係、構造、対応を表したもの。その図は依存関係の map だった。
3ある集合と別の集合の間に対応関係を定める。調査では各名称を場所に map する。
P

package

/ˈpækɪdʒ/
名詞・動詞
1包まれたり箱に入れられたりして一つにまとめられたもの。小さな荷物が郵便で届いた。
2関連する複数のものを一つとしてまとめたもの。その施策は一つの package を形成していた。
3配布や提示のために包む、まとめる。商品は丁寧に包装された。
R

range

/reɪndʒ/
名詞・動詞
1上限と下限の間、または変化しうる範囲。その計器は広い range を持つ。
2二つの限界の間に広がる集合や系列。値は range 全体に及んだ。
3ある領域や区間にわたって広がる、変化する。気温は穏やかなものから厳しいものまで幅がある。

return

/rɪˈtɜːn/
動詞・名詞
1以前の場所、人、状態、活動へ戻る。彼女は暗くなる前に戻った。
2何かを返す、戻す。本を返してください。
3戻ること、帰還。彼の帰還で空気が変わった。
S

select

/sɪˈlekt/
動詞・形容詞
1複数の可能性から選ぶ。利用可能な選択肢から一つ選びなさい。
2最良、最適なものとして慎重に選ばれた。選ばれた少人数が招かれた。
比較 switch

struct

/strʌkt/
名詞・略語
1structure の略。複数の部分を一つの全体として見た構成、構造。その記録は小さな struct として保存された。
比較 interface

switch

/swɪtʃ/
動詞・名詞
1一つのもの、位置、進路、状態から別のものへ切り替える。彼らは席を入れ替えた。
2接続を入切したり回路を切り替えたりする装置。彼は照明のスイッチに手を伸ばした。
3急な、あるいは意図的な変更。口調の切り替わりは即座だった。
T

type

/taɪp/
名詞・動詞
1共通する特徴を持つ人や物の類、型。これは別の type の問題だ。
2ある類を代表する人や物。その標本は珍しい type である。
3キーボードやタイプライターで文字を打つ。彼女は住所を慎重に入力した。
V

var

/vɑː/
名詞・略語
1variable の略。異なる値や形を取りうる量、要素、条件。時間だけが制御されていない var として残った。
