F

False

/fɔːls/
形容詞
1事実や現実に合っていない。その報告は誤りだと判明した。
2本物ではない、偽の。彼は偽名で旅をした。
3誤った信念や印象に基づく。彼らは誤った前提で行動した。
反対語 True

finally

/ˈfaɪnəli/
副詞
1一連の出来事や待機の末に、ついに。ついに扉が開いた。
2最後の点として、最後に。最後に、一つだけ問いが残った。

for

/fɔː; fə/
前置詞・接続詞
1誰か・何かに属する、利益を与える、届くことを意図して。この手紙はあなた宛てです。
2一定の期間にわたって。彼らは三時間待った。
3〜のために、〜を理由として。その町は庭園で知られていた。

from

/frɒm; frəm/
前置詞
1移動、動作、範囲の起点を示す。彼女は駅から歩いた。
2起源、出所、原因を示す。その知らせは海外から届いた。
3分離や区別を示す。一方を他方と見分けるのは難しかった。
N

None

/nʌn/
代名詞
1ある集団のうち一つも、一人もない。手紙は一通も届いていなかった。
2量や部分がまったくない。何も残っていなかった。
3誰も〜ない。誰も答えられなかった。

nonlocal

/ˌnɒnˈləʊkəl/
形容詞・名詞
1特定の場所や目前の範囲だけに限定されない。その効果は nonlocal だった。
2局所的な領域を越えて作用または関係するもの。その理論は nonlocal を許す。

not

/nɒt/
副詞
1語、句、文を否定する。まだ終わっていない。
2可能性を否定、除外する。全員が賛成したわけではない。
3予想されるものとの対照を示す。元のものと似ていないわけではなかった。
T

True

/truː/
形容詞
1事実や現実に合っている。その話は本当だ。
2正確な、正しい位置や状態にある。その車輪はもはや正しく回っていなかった。
3誠実な、忠実な、一貫した。彼女は自分の言葉に忠実だった。
反対語 False

try

/traɪ/
動詞・名詞
1何かをしようと試みる。もう一度やってみなさい。
2品質、適性、効果などを確かめるために試す。彼女はその鍵を錠に試した。
3試み。次の試みではうまくいくかもしれない。
参照 except

and

/ænd; ənd/
接続詞
1同等の語、句、節を結ぶ。パンと水が用意された。
2追加の事実や結果を導く。彼は扉を開け、入った。
3反復する語の間に置き、継続や増大を表す。音はますます大きくなった。
比較 or

as

/æz; əz/
接続詞・前置詞・副詞
1〜している間に、〜するとき。彼女は光が消えていくのを見ていた。
2〜として、〜の役割で。彼は翻訳者として働いた。
3〜と同じ程度に。以前と同じくらい静かだった。

assert

/əˈsɜːt/
動詞
1真実であると強く、確信をもって述べる。彼女は残る権利を主張した。
2権威、存在、立場などを認めさせる。その集団は自己主張を始めた。

async

/eɪˈsɪŋk/
形容詞・略語
1asynchronous の略。同時に起こらない、または単一の共通した時間に従わない。そのやり取りは意図的に async だった。

await

/əˈweɪt/
動詞
1人、出来事、結果などを待つ。彼らは返答を待った。
2〈出来事などが〉将来に待ち受ける。難しい選択が彼らを待っていた。
参照 async
B

break

/breɪk/
動詞・名詞
1力、圧力、負荷などで割る、壊す。枝は自重で折れた。
2流れや連続性を中断する。質問が沈黙を破った。
3休止、中断。彼らは短い休憩を取った。
参照 continue

class

/klɑːs/
名詞
1共通する性質を持つものとして扱われる人や物の集まり。その標本はよく知られた分類に属する。
2大きな体系の中の等級、区分、類。切符は等級ごとに分けられていた。
3一緒に授業を受ける集団。そのクラスは週に二度集まった。

continue

/kənˈtɪnjuː/
動詞
1止まらずに存在、進行し続ける。雨は夜通し降り続いた。
2中断の後で再び始める。少し間を置いて、彼女は話を続けた。
3同じ方向や過程をさらに進む。道が細くなるところまで進みなさい。

del

else

2別の、ほかの。別の誰かが到着していた。

except

/ɪkˈsept/

2例外や但し書きを導く。行きたいが、もう遅すぎる。
3一般的な規則や記述から除外する。その法律はいくつかの場合を除外する。

/ˈɡləʊbəl/

1世界全体に関する、世界的な。その出来事は世界的な影響をもたらした。
2体系全体に関し、一部分だけに限られない。全体的な視点から模様が見えた。
3体系や文脈の全体に適用されるもの。その設定は global として扱われた。
